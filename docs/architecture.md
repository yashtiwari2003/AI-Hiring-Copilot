# AI Hiring Copilot Architecture

## Workflow

1. User uploads a resume (PDF).
2. User uploads a job description.
3. The system extracts text from the resume.
4. The system compares the resume with the job description.
5. The system calculates an ATS score.
6. The system identifies missing skills.
7. The system generates improvement suggestions.
8. The results are displayed to the user.
